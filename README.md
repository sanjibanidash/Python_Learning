# Python Learning 🐍

This repository contains my Python learning journey, including beginner projects, coding exercises, and small applications built while learning Python from the fundamentals.

The focus is on building a strong foundation in **Python syntax, problem-solving, logic building, functions, loops, conditionals, data structures, and working with user input**.

---

## Projects

### 🎮 Rock Paper Scissors
A simple command-line game where the user plays Rock Paper Scissors against the computer.

**Concepts practiced:**
- Conditional statements
- Lists
- Random module
- User input
- Basic game logic

---

### 🔐 Password Generator
A command-line password generator that creates random passwords based on user preferences.

**Concepts practiced:**
- Lists
- Loops
- Randomization

- User input
